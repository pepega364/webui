# krdpilot WebUI deployments

This repository contains only the built static WebUI files (no firmware, bootloader, or main project source).

- `/universal/` — current WebUI, supports telemetry v28 and v31.
- `/a899314/` — WebUI built from commit `a8993141a085beffe82194d90664eb616578605c`.

In GitHub, enable Pages from **Settings → Pages → Deploy from a branch → main → /(root)**. The site URL will be `https://pepega364.github.io/webui/`.
